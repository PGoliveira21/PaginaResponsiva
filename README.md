## 📋 Sobre o Projeto

**MandaTrends** é uma landing page responsiva desenvolvida como projeto de portfólio, simulando um portal de notícias e tendências. O projeto demonstra habilidades em desenvolvimento front-end com foco em criação de layouts adaptáveis e modernos.

### 🎯 Objetivo

Criar uma interface funcional e responsiva que se adapte perfeitamente a diferentes dispositivos (desktop, tablet e mobile), aplicando boas práticas de desenvolvimento web e design responsivo.

---

## 🚀 Funcionalidades

✅ **Layout Responsivo** - Adaptação automática para mobile e desktop  
✅ **CSS Grid Layout** - Estrutura moderna e organizada  
✅ **Design Clean** - Interface intuitiva e profissional  
✅ **Media Queries** - Breakpoints otimizados para diferentes telas  
✅ **Imagens Otimizadas** - Carregamento eficiente e proporcional  
✅ **Semântica HTML5** - Código estruturado e acessível  

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estruturação semântica do conteúdo
- **CSS3** - Estilização e layout
  - CSS Grid para organização da página
  - Flexbox para alinhamentos
  - Media Queries para responsividade
  - Gradientes e efeitos visuais
- **Font Roboto** - Tipografia moderna e legível

---

## 📐 Estrutura do Layout

### Desktop (> 600px)
- Layout em 2 colunas
- Grid organizado com `grid-template-areas`
- Imagens e conteúdo distribuídos de forma equilibrada

### Mobile (≤ 600px)
- Layout em coluna única
- Elementos empilhados verticalmente
- Margens e espaçamentos ajustados
- Imagens redimensionadas proporcionalmente
